# F05 fictional mock-call scenarios

`mock-memory-calls.json` contains project-authored fictional contacts, memories,
and attributed call turns. It reuses the approved project-owned
`assets/f04/basic-video-chat.mp4` fixture for later visible desktop replay. No real
contact data, call recording, screenshot, or generated face was added for F05.

The scenarios cover indirect event reference, pronoun-like follow-up, competing
events, wrong-contact isolation, sensitive cloud permission, unrelated discussion,
and no confirmed contact. Automated checks use fake interpretation output and make
no cloud request. The visible computer-controlled replay remains a separate manual
gate.

The longitudinal workflow adds two same-name contacts and four fictional calls. It
checks proposal evidence against source turns, bulk approval and rejection, immutable
correction, future-call retrieval for the same contact, exact-ID isolation for the
other contact, and bulk deletion with an unselected survivor.
